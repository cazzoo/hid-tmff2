THE PROBLEM (Recap):
====================
- Userspace driver works in native Linux
- Wine/Proton games couldn't see it AT ALL
- Root cause: uinput device isn't visible to Wine
- Wine looks for real USB HID devices

THE SOLUTION:
=============
UHID Proxy - Creates a "fake" T500RS that Wine can see

Architecture:
  Wine Game
     ↓
  UHID Proxy (NEW - Phase 1 done!)
     ↓
  Userspace Driver
     ↓
  Real USB Device
